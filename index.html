DBMS Documentation

Database design and academic concepts.

Project Abstract

AirWatch organizes sensor stations, air-quality readings, historical trends, and pollution alerts using a relational database design.

ER Diagram

USERS
PK user_id
name, email
password_hash, role
SENSORS
PK sensor_id
sensor_name, location
latitude, longitude, status
READINGS
PK reading_id
FK sensor_id
recorded_at, pm25, pm10, co2, aqi
ALERTS
PK alert_id
FK sensor_id, reading_id
alert_type, severity, status

Relationship: one sensor has many readings and alerts. A reading can generate multiple alerts. Users are separate from sensor data.

Functional Dependencies

  • Users: user_id → name, email, password_hash, role, created_at. Unique email also determines the user attributes.
  • Sensors: sensor_id → sensor_name, location, latitude, longitude, status, created_at.
  • Readings: reading_id → sensor_id, recorded_at, pm25, pm10, co2, aqi.
  • Alerts: alert_id → sensor_id, reading_id, alert_type, message, severity, created_at, status.

Normalization

1NF: Fields contain atomic values and rows have unique primary keys.

2NF: Single-column primary keys mean there are no partial dependencies on composite keys.

3NF: Sensor information is stored separately from readings; non-key attributes depend on the key, not on other non-key attributes.

MySQL CRUD and Reports

SELECT * FROM sensors;

INSERT INTO sensors
(sensor_name, location, latitude, longitude, status)
VALUES ('Sensor A', 'Campus', 16.30, 80.45, 'Active');

UPDATE sensors SET status = 'Inactive'
WHERE sensor_id = 1;

DELETE FROM sensors WHERE sensor_id = 1;

SELECT sensor_id, AVG(aqi) AS average_aqi,
MAX(aqi) AS highest_aqi
FROM readings GROUP BY sensor_id;

CREATE VIEW daily_air_quality_summary AS
SELECT DATE(recorded_at) AS reading_date,
COUNT(*) AS total_readings, AVG(aqi) AS average_aqi,
MAX(aqi) AS highest_aqi
FROM readings GROUP BY DATE(recorded_at);

START TRANSACTION;
-- Insert a reading and its alert using the same connection.
COMMIT;
-- Use ROLLBACK instead of COMMIT to undo test changes.

These are academic MySQL examples. This frontend does not execute these queries or connect to MySQL.
